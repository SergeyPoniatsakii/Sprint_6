# Проект Автоматизация тестирования веб-приложения "ЯндексСамокат"

Тестируемые сценарии:
1. Проверка ответов в выпадающем списка в разделе "Вопросы о важном".
2. Проверка позитивного сценария оформления заказа самоката через две точки входа с использованием двух наборов данных.
3. Проверка переходов на страницы Дзен и Яндекс Самокат по клику на логотипы Яндекс и ЯндексСамокат.

## Установка

1. Клонируйте репозиторий на локальную машину:
   ```bash
   git clone https://github.com/SergeyPoniatsakii/Sprint_6.git
   ```
   ```bash
   cd Sprint_6
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск тестов и генерация Allure отчета

1. Запуск тестов:
   ```bash
   pytest --alluredir=allure-results
   ```

2. Генерация и просмотр отчета Allure:
   ```bash
   allure serve allure-results
   ```

## Структура проекта

- **data/** - тестовые данные и URL-адреса, используемые в тестах.
- **locators/** - локаторы элементов страниц.
- **pages/** - Page Object для страниц тестируемого веб-приложения.
- **tests/** - файлы с тестовыми сценариями.
- **conftest.py** - фикстуры для тестов.
- **requirements.txt** - писок зависимостей для проекта.
